About The Research Project

          
System specifications, methodology, and dataset attribution.

        


        

          

            
Project Title

            

              Personalized Federated Deep Learning for Wireless Link Quality Prediction under Non-IID Cell Data
            


            

              Dataset Clarification Note:
              

                The system evaluates RSSI-derived wireless link quality using Wi-Fi fingerprint measurements from the UJIIndoorLoc benchmark dataset. It is not a direct 4G/5G cellular dataset. All signal quality regimes (Poor, Fair, Good, Excellent) are mapped via physical received signal strength boundaries.
              

            


            
Key Innovations

            
    
              
  • Personalized Split Architecture (FedPer): Overcomes client heterogeneity by keeping deep feature extraction shared across federation while training personalized private classification heads locally.
    • 
              
  • Continuous Soft Threshold Integration: Mathematical sigmoid branches embedded directly in the neural graph to provide continuous awareness of physical signal transition zones.
    • 
              
  • Locked Margin-Hybrid Strategy: Uses deterministic RSSI physical boundaries for 93.5% of points and routes only boundary-ambiguous samples within 0.25 dBm to personalized neural inference, achieving 97.93% test accuracy and 98.42% balanced accuracy.
    •
